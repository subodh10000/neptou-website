# Neptou - Tourism Website for Nepal

A beautiful, modern website for Neptou, the ultimate tourism app for discovering Nepal. Built with Next.js, React, TypeScript, Tailwind CSS, and Framer Motion.

## ✨ Features

- 🏔️ **Stunning Hero Section** with animated Himalayan mountains and dynamic background
- 🎌 **Prayer Flags Animation** - Traditional Nepalese prayer flags flowing across the top
- 🎯 **Interactive Features Section** - Showcasing all app capabilities with smooth animations
- 📱 **iOS App Download CTA** - Eye-catching call-to-action with phone mockup
- 🎨 **Nepal-Inspired Design** - Colors and animations reflecting Nepal's culture
- ⚡ **Smooth Animations** - Powered by Framer Motion for delightful user experience
- 📱 **Fully Responsive** - Optimized for all devices and screen sizes
- 🎭 **Creative Elements** - Mandalas, mountains, stars, and cultural motifs

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view the website.

## 🛠️ Tech Stack

- **Framework:** Next.js 15
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Heroicons (SVG)
